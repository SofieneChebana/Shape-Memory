Projet du 2ème semestre de la 1ère année de master informatique 2024/2025.

• Titre :

Mémorisation de formes.

• Description :

Le but de ce jeu est de mémoriser des formes et de les reproduire correctement pendant une phase de reproduction.
    - Règles : 
        Au début du jeu, un dessin de référence est généré. Ce dessin comporte plusieurs formes (cercles et/ou rectangles). Après un temps d'observation de 10 secondes, le joueur doit reproduire le dessin en utilisant des outils de dessin (ajouter des cercles, des rectangles, déplacer ou supprimer des formes). Le score est calculé en fonction de la similitude entre les formes du dessin de reproduction et celles du dessin de référence. Le joueur doit respecter le placement et la taille des formes pour obtenir un score élevé.
    - Modes de Jeu :
        - 1 joueur : Vous jouez seul, avec un seul dessin de référence et un seul joueur pour la reproduction.
        - 2 joueurs : Deux joueurs alternent pour la phase d'observation et la phase de reproduction, chacun devant essayer de reproduire le dessin de l'autre.

• Comment exécuter le projet

Avant de d'éxécuter les commandes il faut se placer dans le dossier livraison.

Lancer le jeu (initialisation + compilation + test + lancement) :
    - ant run
Générer la javadoc : 
    - ant javadoc
Initialiser le répertoire "build" du projet :
    - ant init
